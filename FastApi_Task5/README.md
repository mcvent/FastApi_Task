# FastAPI Blog API

Блог-API с JWT, множественными изображениями, Dishka DI и полной асинхронностью на PostgreSQL.

---

## Технологии

| Компонент | Технология |
|-----------|------------|
| Фреймворк | FastAPI 0.135+ |
| Асинхронность | ASGI (Uvicorn) |
| БД | PostgreSQL 17 + asyncpg |
| ORM | SQLAlchemy 2.0 (async) |
| DI контейнер | Dishka 1.10+ |
| Авторизация | JWT |
| Валидация | Pydantic 2.x |
| Контейнеризация | Docker Compose |

---

## Возможности

**Пользователи:** регистрация, JWT, просмотр/редактирование профиля, удаление (сам или админ)

**Посты:** CRUD (только автор), пагинация, фильтрация, **множественные изображения** (до 10 шт.)

**Комментарии:** CRUD (автор или админ), **изображения к комментариям**

**Категории/Локации:** CRUD (только админ)

---

## Архитектура

API Layer → Use Cases → Repositories → Models

DI через Dishka. Правила:
- **CREATE/UPDATE/DELETE** — `__init__(session, repo)`
- **GET** — `__init__(repo)`, `session` в методах

## Запуск проекта

```bash

# Отредактируйте .env

Открыть http://127.0.0.1:8000/docs
```
